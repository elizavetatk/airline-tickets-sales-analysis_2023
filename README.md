# Анализ продаж авиабилетов

Учебный проект по дисциплине «Анализ данных» (декабрь 2023) — один из первых проектов по аналитике на Python. 

## О данных

Каждая строка датасета — уникальная покупка билета. Поля:
- `ISSUE_DATE` — дата покупки
- `FLIGHT_DATE_LOC` — дата совершения перелета
- `PAX_TYPE` — тип пассажира
- `REVENUE_AMOUNT` — сумма (значения скорректированы, но пропорции сохранены)
- `ORIG_CITY_CODE`, `DEST_CITY_CODE` — город отправления / назначения
- `ROUTE_FLIGHT_TYPE` — тип перелёта 
- `FFP_FLAG` — наличие программы лояльности
- `SALE_TYPE` — способ покупки

Дополнительные данные по аэропортам: [openflights/airports.dat](https://raw.githubusercontent.com/jpatokal/openflights/master/data/airports.dat)

## Что внутри

1. **Предобработка данных** — приведение заголовков, проверка типов, обработка пропусков, поиск дубликатов, исключение нулевой выручки.
2. **Динамика продаж** — выручка во времени с детализацией по FFP, типу перелёта и способу покупки.
3. **Работа с выбросами** — анализ выручки, исключение выбросов с минимизацией потерь в данных.
4. **Сезонность** — продажи по месяцам, проверка гипотезы о различии выручки осенью и зимой, корреляция выручки и числа продаж.
5. **Время покупки** — разбиение клиентов минимум на 3 группы по тому, насколько заранее они покупают билеты, и проверка гипотезы о различии выручки между группами.
6. **Топ-10 направлений** — отдельно для ВВЛ и МВЛ, с обогащением данными о городах из датасета аэропортов.
7. **Взаимосвязи признаков** — матрица корреляций выручки с другими признаками.

Каждый раздел сопровождается выводами.
